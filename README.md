## 📝 Description

ViTGalaxyClassifier is a deep learning project dedicated to classifying galaxy images using Vision Transformer (ViT) models. Automated classification of galaxy imagery is a key task in observational astronomy, helping researchers process large-scale astronomical survey datasets efficiently.

The project is implemented through an interactive Jupyter Notebook workflow (ViTGalaxiesClassifier.ipynb). It leverages vision transformer architectures to process image inputs and generate classification predictions for astronomical targets.

This repository serves as a starting point for astronomers, data scientists, and machine learning researchers exploring the application of transformer models to astronomical image datasets.

## ✨ Key Features

- **🌌 Galaxy Image Classification Model** — Applies Vision Transformer models to perform automated image classification on galaxy datasets.
- **📓 Jupyter Notebook Driven Workflow** — Executes the model implementation and image processing within the ViTGalaxiesClassifier.ipynb notebook.
- **🤖 Vision Transformer Architecture Implementation** — Leverages transformer-based computer vision techniques to evaluate visual features in astronomical imagery.

## 🎯 Use Cases

- Classifying galaxy images using Vision Transformer models.
- Benchmarking deep learning transformer architectures on astronomical image datasets.
